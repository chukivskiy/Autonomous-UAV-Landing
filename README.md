# Autonomous-UAV-Landing
System for autonomous emergency landing of VTOL drones in non-antopogenic environments using semantic segmentation (U-Net, FPN, SegFormer), Archimedean spiral search and PID-controlled descent. Implemented with ROS 2, PX4 and Isaac Sim
